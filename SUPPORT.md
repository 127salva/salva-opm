# Support

This is a personal project for one laptop model; there is no guaranteed support.

1. Read [docs/troubleshooting.md](docs/troubleshooting.md): it covers every warning the window can show.
2. Check [docs/what-it-does.md](docs/what-it-does.md) to see whether the behaviour is intended.
3. Still stuck: open an issue with the bug template and attach `C:\ProgramData\SalvaOPM\log.txt`.

If the laptop behaves badly (heat, fans), uninstall first: run the setup again → **Uninstall**. The firmware takes the fans back at once; a power limit left by Performance lapses within about two minutes.
